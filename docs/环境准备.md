# 环境准备

本项目**不打包**任何模型权重，也不打包 PyTorch。第一次运行要把这些装起来。
装一次，以后不用再装。

## 一、你得自己装的两样

| 东西 | 版本 | 为什么 |
|---|---|---|
| **Python** | **3.10 / 3.11 / 3.12**（推荐 3.11） | PyTorch 2.4.0 只给这几个版本出了 Windows 轮子。3.13 装不上 |
| **ffmpeg** | 任意较新版本，要带 ffprobe | 合成与校验全靠它，本项目不替你装 |

**Python**：到 python.org 下 3.11 的安装包，安装时**勾上 Add python.exe to PATH**。

**ffmpeg**：Windows 上最快的一条是

```
winget install Gyan.FFmpeg
```

装完**关掉命令行窗口重开**，PATH 才会生效。验证：

```
ffmpeg -version
```

能打出版本号就行。macOS 用 `brew install ffmpeg`，Ubuntu 用 `apt install ffmpeg`。

## 二、剩下的交给一键脚本

双击 **`一键环境.bat`**。它先查一遍现状，再只做缺的那几件：

| 步骤 | 内容 | 下载量 | 装完占地 |
|---|---|---|---|
| 1 | 拉 CosyVoice 源码（git clone，没有 git 就下 zip） | 约 50 MB | 约 0.1 GB |
| 2 | 在项目目录下建独立环境 `.venv`（不污染你的 Python） | — | 忽略 |
| 3 | 装 PyTorch 2.4.0（cu121） | 2.4 GB | 4.2 GB |
| 4 | 装推理依赖 ＋ openai-whisper | 约 1.2 GB | 约 1.2 GB |
| 5 | 下模型权重（只拉推理要用的那几份） | 5.05 GB | 5.05 GB |

**合计下载约 8.8 GB，装好占约 11 GB。**视网速几十分钟。

环境已经齐了的话，它只说一句「可以开工」，一个字节都不下。缺东西时它先把
缺什么、要下多少、磁盘够不够说清楚，按了回车才开始装。装完它自己再查一遍，
缺的那几行变成 OK 才算完。

中途断了直接重跑：装过的步骤跳过，没下完的模型接着下，不会从零开始。

不想在窗口里按回车就加一个参数：

```
python app.py --setup --yes
```

只看不装：双击 `启动-自检.bat`，或者 `python app.py --check`。
`启动.bat` 菜单里的 `0` 也是这个一键脚本。

## 三、硬盘和显卡

| | 要求 |
|---|---|
| 磁盘 | 约 11 GB 空闲 |
| 显卡 | N 卡，**6 GB 显存起步**（本项目按 16 GB 实测：整篇跑下来峰值 4.5 GB 上下） |
| 没 N 卡 | 能跑，走 CPU。装的时候加 `--cpu`，速度慢十倍上下 |

CPU 也能出东西，只是慢。一台普通笔记本跑 8 分钟的故事，大概要等到四十分钟以上。

## 四、这个项目替你避开的三个坑

装环境最容易失败的地方不在网络，在版本。这三条都写进代码了，你不需要再踩一遍。

### 1. 不要用上游要求的 `torch==2.3.1`

上游 `requirements.txt` 锁的是 2.3.1。这个版本的 **Windows 轮子漏打包了整套 MKL**：
`import torch` 能过、CUDA 能过，可一旦跑到 CPU 的 `svd` / `inv`（语音处理里到处都是），
**整个进程会静默死掉**，退出码 `3228369022`（0xC06D007E），没有 Python 报错、没有堆栈。

更麻烦的是它不稳定：同一个文件、同一个环境变量，两次跑结果不一样 ——
说明是 MKL 运行时自动探测的时序问题，不是缺文件。补 MKL 那 23 个 DLL 也不管用。

**本项目锁 2.4.0。**它的 `torch_cpu.dll` 导入表里一个 mkl 都没有，已验证。

### 2. 不能装 `tensorboard`

`tensorboard==2.14.0` 要求 `protobuf>=3.19.6,<4.24.0`，而 CosyVoice 要 `protobuf==4.25`。
两者互斥，pip 直接 `ResolutionImpossible`。

而 tensorboard 只被 `cosyvoice/utils/train_utils.py` 用，那个文件是训练专用的，
第一行就 `import deepspeed`，推理路径根本不进。所以 `requirements.txt` 里把它删了。

### 3. `openai-whisper` 非装不可

`cosyvoice/cli/frontend.py` 第一行就是 `import whisper`。缺了它，**连模型都加载不了**，
报的错却看不出跟 whisper 有关系。

它是源码包，安装时加 `--no-build-isolation` 才装得干净。

## 五、下不动怎么办

模型走的是 Hugging Face，国内直连常常拉不动。安装器默认把域名换成
`hf-mirror.com`（`HF_ENDPOINT`），路径不变。

PyTorch 走官方源 `download.pytorch.org`。如果这条慢，可以手动换成上海交大的镜像：

```
.venv\Scripts\python.exe -m pip install torch==2.4.0 torchaudio==2.4.0 ^
    --index-url https://mirror.sjtu.edu.cn/pytorch-wheels/cu121
```

其他 pip 依赖走的是阿里云镜像，一般不会卡。

## 六、想自己确认装对了

双击 `启动-自检.bat`，或者

```
python app.py --check
```

它会列出：ffmpeg 版本、源码在不在、torch 版本、CUDA 可不可用、显卡型号、
模型七项各有多大、工程目录里的素材齐不齐。**只看，不装，不改。**

一键环境（`一键环境.bat` / `app.py --setup`）比它多一步：查完之后，
缺什么就接着装什么。
