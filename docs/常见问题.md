# 常见问题

## 装环境

**卡在「装 PyTorch」很久不动。**
正常。cu121 那个轮子 2.4 GB，加上解包，十几分钟不算慢。想确认它没死，
看磁盘可用空间是不是在减少。

**报 `No matching distribution found for torch==2.4.0`。**
你的 Python 版本不在 3.10 / 3.11 / 3.12 里。多半是 3.13。
装一个 3.11，再删掉项目目录下的 `.venv`，重跑安装。

**报 `ResolutionImpossible`，提到 protobuf。**
说明你装的是上游那份 `requirements.txt`，不是本项目带的这份。
本项目已经把 `tensorboard` 删了，因为要与 `protobuf==4.25` 打架。

**模型下到一半断了。**
重跑安装，会断点续传。已下的不会重来。

**`ffmpeg` 装了还是说找不到。**
PATH 没生效。**关掉窗口重开**，或者重启一次。装完不重启就运行是最常见的原因。

## 出旁白

**报 `assert ... <= 30` 或者「超了」。**
参考录音超过 30 秒。引擎这里是硬断言，不会自动截断。
重录一遍更短的，或者把录音断在最后一句完整的话上，文字也跟着改。

**跑完听着不像我。**
先看参考录音，九成问题在这一步：

| 症状 | 原因 |
|---|---|
| 声音闷、发糊 | 手机录音开了「降噪 / 人声增强」，把 4 kHz 以上削掉了 |
| 有嗡嗡的低频 | 手机贴着嘴录的，近场喷麦 |
| 有回声、空洞 | 在浴室、厨房、空房间录的 |
| 听着像播音员 | 你念得太用力了。要的是你哄孩子的口气 |

录之前把降噪关掉，手机离嘴 20~30 厘米。这一条比换任何参数都管用。

**念到第 12 段报错停了。**
修好之后直接重跑，**已经念好的段会跳过**。每段都单独存了 wav，
碎片都在 `旁白/` 里，文件名是 `seg_001.wav` 这样。

**我改了参考录音，出来的还是旧声音。**
断点续传按「文件在就跳过」判断，认的是 `旁白/seg_XXX.wav` 是否存在。
换了参考录音或语速，**先把 `旁白/` 里的 wav 清空**，否则会把上一版拼进来 ——
这种错不报错，只出错东西。

**只跑前三段的时候，没有「全篇」。**
故意的。缺段的全篇比不拼更危险，所以只有每一段都成功才拼。

## 合成成片

**报「配乐只有 X 秒，太短了」。**
配乐短于 12 秒没法循环出音垫。换一段长一点的。

**配乐比故事短会怎样。**
会自动循环，接头用 4 秒交叉淡接，听不出接缝。想完全没有循环，
就用一段比故事长的曲子。

**不想要音乐。**
工程目录里别放 `配乐.mp3`。它只出旁白，同样会做淡入淡出。

**为什么不替我作曲。**
作曲是另一件事。本项目只负责「把已经有的曲子垫在旁白下面」。
要本机作曲，ACE-Step 那类工具能出，出来的 wav 直接放进来就行。

**出来的人声比音乐响太多 / 太轻。**
去 `config.json` 调 `bed_below_db`。默认是音乐垫比旁白低 24 dB。
调小（比如 18）音乐会响一点，调大（比如 30）更轻。

## 校验

**某一条不通过怎么办。**
先看它量的是什么，再决定要不要动：

| 不通过的项 | 多半是什么 |
|---|---|
| 时长不符 | 改了 `lead` / `tail` 但没重新混音 |
| 引子没有音乐 | 配乐开头那几秒本身就是弱奏。换一段，或者让它从别处开始 |
| 旁白进场位置不对 | 改动过 `lead`，重跑合成即可 |
| 旁白有空隙超过 1.5 秒 | 故事里本来就有大段留白，或者某一段念空了 |
| 音乐垫中断 | 配乐不够长又没循环起来（不该发生，出现了请提 issue） |

**「峰值因数」这类词看不懂。**
不用管。校验要拦的是四件要命的事：削顶、时长不对、旁白有大段空洞、
音乐中途断了。其余的数字是给你留档的。

## 其他

**能换成别人的声音吗？**
不能。拿别人的声音做内容属于侵权，录音是不是你自己录的、是不是你自己买的，
都不影响这个判断。**只做自己的声音。**

**能商用吗？**
代码是 MIT。上游 CosyVoice 与模型是 Apache-2.0，两者都允许商用，
但要遵守各自的条款，见 `NOTICE.md`。真要做成生意，自己再核一遍许可证。

**这套东西要钱吗。**
不调任何付费接口。成本是电、时间和 12 GB 硬盘，不是钱。
