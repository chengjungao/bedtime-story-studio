# 用你的声音读睡前故事

**把你写的故事，用你自己的声音念出来，垫上音乐，做成一段能直接放给孩子听的音频。**

不用会剪辑，不用写代码。录一段十几秒的录音，剩下的交给它。

全程在你自己的电脑上跑：不联网、不排队、不调任何付费接口。

| | |
|---|---|
| 输入 | 一份故事 ＋ 一段 15~28 秒的录音 ＋ 那句录音的逐字文字（＋ 可选的一首曲子） |
| 输出 | 一条 wav ＋ 一条 mp3，44.1 kHz 立体声，带 2 秒引子、6 秒收尾 |
| 实测 | 1285 字的故事 → 22 段 → **493 秒旁白** → 成片 **501 秒（8 分 21 秒）** |

底层用的是 [CosyVoice3](https://github.com/FunAudioLLM/CosyVoice) 的零样本克隆。
本项目只做三件事：把环境装起来、把流程串起来、把每一步该看到什么说清楚。

---

## 这个项目解决什么问题

零样本克隆的模型早就公开了，难的是**从一段录音走到一条能播放的成品**：

| 卡在哪 | 这里怎么处理 |
|---|---|
| 模型加载要写的代码一堆，还要手动塞 sys.path | 双击就行。装环境、跑推理都包好了 |
| 整篇丢进去，跑到一半断了，前面白跑 | 先按官方同一套规则切段，**逐段存盘**。断了重跑会跳过已完成的 |
| 段拼起来接缝处有咔哒 | 官方分段后段间**不加静音**，那点换气声是模型自己产生的。加固定静音反而听着机械 |
| 语速比真人快一截，念睡前故事像赶场 | 语速 0.85。实测 3.21 字/秒，作者本人 3.09 字/秒。默认 1.0 是 3.77，快 22% |
| 配乐一垫，人声就听不清了 | 旁白归一到 −22 dBFS，音乐垫**再比旁白低 24 dB**。两边都量，按差值定 |
| 引子开头一片死寂 | 选配乐起点时，**按头 2 秒有多响**来排，不看整段均值 |
| 出来了不知道对不对 | 出厂校验一条一条量：采样率、削顶、淡入淡出斜率、旁白进场点、空隙、音乐中断 |

## 先看能不能接受

| | 要求 |
|---|---|
| 显卡 | **N 卡**，6 GB 显存起步（本项目按 16 GB 实测：整篇峰值 **4.43 GB**） |
| 磁盘 | **约 11 GB** 空闲（模型 5.05 GB ＋ PyTorch 落地 4.2 GB ＋ 依赖 1.1 GB） |
| 系统 | Windows 10 / 11（双击入口是 Windows 的，macOS / Linux 用 `./start.sh`） |
| 其余 | **Python 3.10~3.12**；**ffmpeg**（合成与校验必需） |
| 时间 | 模型加载 **16 秒**；出旁白 **RTF 0.536**（8 分钟的故事约 4 分半） |

**本项目不包含** CosyVoice 源码、模型权重、PyTorch 和 ffmpeg。
前三个由安装器自动装，ffmpeg 要你自己装。步骤见 **[docs/环境准备.md](docs/环境准备.md)**。

> 没有 N 卡也能跑：装的时候加 `--cpu`，走 CPU，慢十倍上下。

## 怎么用

### 1. 放四样东西进「我的故事」

```
我的故事/
├── 故事.txt          ← 你写的故事。空行分段，一段两三句
├── 参考录音.m4a      ← 你的声音，15~28 秒。手机录完直接丢进来
├── 参考录音.txt      ← 上面那段录音的逐字文字
└── 配乐.mp3          ← 可选。不放就只出旁白
```

第一次运行会自动建好这个文件夹和模板文件。

不想自己写故事，可以用示例：`python app.py --example`，会把一份
1285 字的故事和配套的参考文本放进「我的故事」。

### 2. 双击「一键环境.bat」

第一次跑，先双击这个。它先查一遍现状，再决定做什么：

```
  环境
    项目            状态  说明
    启动器 Python   OK    3.12.7
    ffmpeg          OK    7.1
    CosyVoice 源码  缺    要拉下来，约 50 MB
    PyTorch         OK    torch 2.4.0+cu121  CUDA 可用  RTX 4080 16.0 GB
    模型            缺    缺 6 项，要下 4.13 GB
```

全都齐了，它只说一句「可以开工」，一个字节都不下。缺东西时它先把缺什么、
要下多少、磁盘够不够讲清楚，按了回车才开始：

```
1/5  拉 CosyVoice 源码（约 50 MB）
2/5  建独立环境（不污染你机器上的 Python）
3/5  装 PyTorch 2.4.0（下载 2.4 GB，落地 4.2 GB）
4/5  装推理依赖 ＋ openai-whisper（约 1.1 GB）
5/5  下模型（5.05 GB，只拉推理要用的）
```

装完它自己再查一遍，缺的那几行变成 OK 才算完。中途断了直接重跑，
装过的跳过，没下完的接着下。`启动.bat` 菜单里的 `0` 是同一个东西。

不想在窗口里按回车：`python app.py --setup --yes`。

它不替你装 Python 和 ffmpeg，这两样要动系统。缺 ffmpeg 时它会把
`winget install Gyan.FFmpeg` 这条命令打给你，装完重开窗口再跑一次。

### 3. 菜单上三步走

```
  0  装环境        1  出旁白        2  合成成片        3  出厂校验
                    你的声音         垫音乐、排引子      一条一条量过去
```

第一次建议先选 `5`（只跑前 3 段），听听像不像你，再跑全篇。
一篇 8 分钟的故事，出旁白四分半。

## 参考录音怎么录

这一步决定成品像不像你，比任何参数都重要。

| 项 | 怎么做 | 为什么 |
|---|---|---|
| 环境 | 安静卧室，拉上窗帘。**别**在浴室、厨房、空房间 | 回声会被当成音色的一部分学进去 |
| 位置 | 手机离嘴 **20~30 厘米**，别贴嘴 | 贴嘴会进来近场喷麦和低频隆隆声 |
| 时长 | **15~28 秒**。硬上限 30 秒 | 引擎里那条 assert 超了就直接报错，不截断 |
| 语气 | 用你哄孩子的样子说：放慢、放软、带自然的停顿和呼吸 | 引擎学的是「你怎么说话」，不只是「你声音长什么样」 |
| 文字 | 照着一份稿件念，念完把稿子抄进 `参考录音.txt` | 见下 |
| 格式 | 手机自带的录音就行，m4a / wav / mp3 都认 | 程序会自己转成 16 kHz |

**录之前把「降噪 / 人声增强」关掉。**那个开关会把 4 kHz 以上削掉，
成品会照着参考录音的频宽走，出来就是闷的。

**念错了不要重录。**接着说就行。磕巴、停顿、笑场都留着 ——
那些恰恰是「像不像你」的一部分。网上做「大爷音」的经验正好是反的：
拿播音腔练出来的模型，出来像个退休播音员。

### 为什么非要配一份文字

零样本克隆要同时喂「音频」和「它到底说了什么」。文字对不上**不会报错**，
只会把音色带偏 —— 属于不报错只出错东西的那一类。所以宁可事先硬卡。

示例工程里带的就是该照念的那段：

> 天黑了，窗外的风也放轻了脚步。小熊把玩具一件一件收进柜子里。
> 最后一件，是它最喜欢的红色小汽车。它轻轻说：明天见。

49 个字，正常念 18~20 秒。

## 这台机器上的账

示例那篇 1285 字、48 个自然段，引擎切出来 22 段：

| | 实测值 |
|---|---|
| 模型加载 | 16.3 秒 |
| 切段 | 22 段 |
| 出旁白 | 493.0 秒音频，耗时 264.5 秒，整体 **RTF 0.536** |
| 单段 RTF | 0.512 ~ 0.573（中位 0.534） |
| 峰值显存 | 4.39 ~ 4.43 GB |
| 合成成片 | 引子 2.0 ＋ 旁白 493.0 ＋ 收尾 6.0 ＝ **501.0 秒** |
| 出厂校验 | 10 条全过 |

语速 0.85 是定过的：合成 3.21 字/秒，作者本人四段录音合计 3.09 字/秒，差 3.9%。
默认 1.0 出来是 3.77 字/秒，比真人快 22%，念睡前故事偏赶。

## 下面这些事我不替你做

* **不替你写故事。**故事是你自己的，这个项目的价值有一半在这。
* **不替你录音。**手机录音笔都行，念稿这件事没有捷径。
* **不替你作曲。**配乐放一个 mp3 进来即可；本机作曲是另一件事。
* **不替你听。**校验能量「旁白是不是从 2.0 秒开始」，量不了「好不好听」。
  最后一遍得你自己听。
* **不含模型权重。**体积太大，也各有各的许可证，见 [NOTICE.md](NOTICE.md)。

## 目录结构

```
用你的声音读睡前故事/
├── 一键环境.bat          双击这个：先查，缺什么装什么
├── 启动.bat              双击这个出菜单
├── 启动-自检.bat         只看缺什么，不装东西
├── setup.sh              macOS / Linux 的一键环境
├── app.py                入口（--setup / --check / --install / --tts / --mix / --all）
├── config.json           所有可调项，首次运行自动生成
├── config.local.json     本机的解释器路径、CosyVoice 装在哪（不进仓库）
├── requirements.txt      依赖清单（与上游有三处不同，每处都写了原因）
├── story_studio/         核心代码
│   ├── config.py         路径、默认值、解释器探测
│   ├── setup.py          一键环境（先查，缺什么装什么，装完再查）
│   ├── envcheck.py       自检（只看在不在、够不够大）
│   ├── installer.py      装环境（源码 / 环境 / PyTorch / 依赖 / 模型）
│   ├── project.py        工程目录、素材校验、录音转码
│   ├── tts.py            出旁白（派活给装了 torch 的解释器）
│   ├── worker_tts.py     真正的推理，跑在独立环境里
│   ├── mix.py            混音（ffmpeg 滤镜图）
│   ├── verify.py         出厂校验
│   ├── media.py          ffmpeg / ffprobe 封装 ＋ 纯标准库的 wav 测量
│   └── ui.py             终端输出
├── examples/             示例工程（1285 字的故事 ＋ 参考文本）
├── docs/                 环境准备、常见问题
└── CosyVoice/            ← 装完才出现，上游源码
    .venv/                ← 装完才出现，独立环境
```

**工程目录**（默认 `我的故事/`）：

```
我的故事/
├── 故事.txt          你写
├── 参考录音.*        你录
├── 参考录音.txt      你抄
├── 配乐.mp3          可选
├── 旁白/             本项目写：seg_001.wav … ＋ 全篇_拼接.wav
├── build/            本项目写：转码后的参考录音
└── 成片/             本项目写：有声故事.wav / .mp3 ＋ 两份 json
```
